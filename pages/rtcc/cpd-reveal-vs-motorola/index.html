Strategic Recommendation
Not Competitors — A Layered Stack
CommandCentral Aware — The Nervous System

Deploy as CPD's permanent enterprise infrastructure layer. Manages the city-wide common operating picture, 911/CAD backbone, camera network aggregation, unit tracking, body camera compliance, and cross-agency coordination. The foundational platform every other system feeds into.

  • RTCC operations hub for CPD
  • Consent decree documentation & audit trail
  • ShotSpotter, LPR, BWC integration point
  • Intra/inter-agency communication spine
Reveal Technology — The Tactical Edge Layer

Deploy as the field-portable intelligence layer for SWAT, specialized units, and event security. Operates where CommandCentral can't reach — offline, at the scene, with sub-10-minute 3D terrain modeling from CPD's existing drone fleet and biometric identification from officers' mobile devices.

  • SWAT pre-breach intelligence & planning
  • Large event venue 3D pre-modeling
  • Field identity verification (Identifi)
  • Federal task force ATAK integration
Integration Point — ATAK + CommandCentral Bridge

The strongest deployment architecture links Reveal's ATAK output into CommandCentral's common operating picture. Tactical intelligence generated by Farsight in the field (terrain models, LOS analysis, HLZ) gets shared to the RTCC via ATAK export, giving command the same picture SWAT has at the edge.

  • Drone-generated 3D data populates COP
  • Identifi geo-tagged contacts feed investigative records
  • Bidirectional intelligence: command ↔ field
CPD Consent Decree Alignment

Both platforms contribute measurably to CPD's ongoing DOJ consent decree obligations — in different but complementary ways that a technology-forward compliance narrative can leverage.

  • Motorola: Missions audit trail → DOJ after-action reporting
  • Motorola: BWC auto-activation → use-of-force documentation
  • Reveal: Identifi geo-tagged contacts → encounter accountability
  • Reveal: 3D LOS analysis → officer positioning justification
