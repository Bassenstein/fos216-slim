Section 05 · Software Platform

Skydio Software Stack

Skydio's software architecture is designed to make drone deployment as routine as dispatching a patrol unit — with zero friction between dispatch trigger and airborne sensor.

SOFTWARE 01
DFR Command (DFRC)
Operational backbone for DFR programs. Flight Deck interface with live CAD calls embedded directly in the pilot's view — no switching between platforms. Processed 10M+ calls for service as of February 2026. Creates real-time AR markers on incoming calls.
SOFTWARE 02
Remote Ops
BVLOS (beyond visual line of sight) management via any web browser. Enables multi-dock fleet management, scheduled mission automation, and real-time fleet health dashboards. Used to manage Dock for X10 deployments remotely.
SOFTWARE 03
3D Scan
Autonomous 3D mapping and crime/crash scene reconstruction. X10 autonomously generates photogrammetric models for documentation, court evidence, and spatial intelligence. Replaces manual scene measurement with automated aerial capture.
SOFTWARE 04
Skydio Autonomy
The core AI flight stack powering obstacle avoidance, subject tracking, GPS-denied navigation, and multi-drone coordination. Enables X10 to operate without constant operator input — freeing RTCC analysts for command decisions rather than flight control.
SOFTWARE 05
Skydio Connect
Communication and telemetry management layer handling multi-radio handoffs, 5G/LTE/Wi-Fi switching, and Starlink integration. Maintains link continuity across Cleveland's urban RF environment.
SOFTWARE 06
Skydio Extend
Open integration platform with developer APIs and 25+ native integrations. Connects DFR Command to CAD systems, gunshot detection, ALPR, body-worn cameras, NG911, and evidence management. Enables Motorola CommandCentral and Axon Evidence integration for CPD.

The Axon Evidence integration is native and requires no additional configuration for CJIS-compliant evidence storage.

Section 07 · Cleveland Division of Police · Proposed Deployment

CPD Justice Center DFR Hive Configuration

The proposed CPD deployment positions three Skydio X10 drones paired with three Dock for X10 autonomous launch stations on the Justice Center headquarters rooftop — forming a coordinated DFR hive as the aerial intelligence layer of the integrated RTCC stack. Airborne in 20 seconds from any CommandCentral dispatch, feeding live FLIR thermal video directly into the RTCC before the first patrol unit arrives on scene.

A
Dock A · X10 Unit 01
Primary Response
Auto-launches on any Priority-1 CAD dispatch within a 2-mile radius of HQ. ShotSpotter trigger, ALPR alert, officer APX NEXT radio activation, or RTCC analyst manual dispatch. On scene before first patrol unit in most downtown CPD 3rd District scenarios.
B
Dock B · X10 Unit 02
Relief / Simultaneous
Continuous on-station coverage when Unit 01 battery depletes. Also provides simultaneous second-incident coverage — ensuring CPD is never without aerial ISR during concurrent high-priority events. Key for pursuit, barricade, and extended scene operations.
C
Dock C · X10 Unit 03
Hot Standby / Surge
Reserved for large events, dignitary protection, SWAT deployment, or a third concurrent incident. Enables uninterrupted coverage during high-demand periods — including downtown events, Browns/Guardians/Cavaliers game nights, and protest management scenarios.

  • BRINC stronger on CommandCentral; Skydio stronger on Axon and evidence integration
